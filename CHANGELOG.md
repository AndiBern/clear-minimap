# Changelog

## 0.3.0 (unreleased)

- Outline the player marker and draw it above other minimap elements.

- Add separate visibility toggles for teammates, properties, deals, objectives,
  and places alongside the NPC toggle.

- Show native phone-map NPC icons by default, respecting native icon visibility.

- Add zoom from 0.5× to 4× while preserving map and marker alignment.

- Add configurable zoom shortcuts through ModSettings, defaulting to PageUp and
  PageDown.

- Add corner selection and horizontal and vertical margins, keeping the frame
  and clock inside the viewport when space permits.

- Require ModSettings 0.3.0.

- Update the package icon and release tooling.

## 0.2.1 — 2026-10-19

- Simplify minimap state and settings handling.

## 0.2.0 — 2026-09-20
